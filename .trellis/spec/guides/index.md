# Cross-Boundary Guides

These guides apply when a change crosses plugin components, provider payloads,
persisted settings, or the Hermes bridge.

| Guide | Use it when |
| --- | --- |
| [Reuse And Ownership](./reuse-and-ownership.md) | Adding helpers, constants, adapters, or translation keys |
| [Boundary Review](./boundary-review.md) | Changing data flow between external APIs, QML state, files, or HTTP |

Read the relevant plugin or bridge index first; these guides do not replace
the layer-specific contracts.
