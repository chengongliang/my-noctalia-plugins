# Market Watch 币种分时详情图

## 目标

让用户点击 Market Watch 行情列表中的具体资产，在原弹窗查看最近 24 小时的价格走势，并读取某个采样点的时间和价格。

## 背景与已确认事实

- 当前 `watch` 面板为 600×495，几何由宿主管理：`market-watch/plugin.toml:131`。
- 资产行目前没有点击行为：`market-watch/panel.luau:123`。
- 现有报价只保存行情快照，没有日内历史；日 K / simple-price 请求在 `market-watch/lib/providers.luau:330`。快速涨跌提醒的内存样本仅覆盖被监控资产和提醒窗口，不能充当通用历史：`market-watch/service.luau:816`。
- 贵金属和美股相关资产是当前数据源的交易所挂牌合约，不是直接证券行情：`market-watch/README.md:126`。
- 已通过三轮 grilling 确认下述产品决定；用户于 2026-11-03 确认最终范围，并授权创建规划文件。

## 需求

### R1 入口和导航

点击币种整行，在同一个行情弹窗进入资产详情；提供返回列表按钮。关闭整个弹窗后，下次打开从列表开始。详情使用宿主设定的面板几何，不新增独立弹窗。

### R2 图表范围和采样

首版固定最近 24 小时的价格折线图，优先采用约五分钟一个点。使用来源实际提供的时间、价格和采样精度，并标明精度；不足整天的数据明确展示实际覆盖范围，不补造历史。

### R3 资产和来源

覆盖当前四个数据源中有历史数据的自选资产，包括加密货币、贵金属及美股相关合约。沿用当前数据源、现货/合约类型、完整资产标识及代理配置；没有历史数据时明确说明不可用，不替换为其他来源或同名资产。

### R4 读数和时间

鼠标悬停时，在图表上方显示对应真实采样点的时间和价格。时间刻度、悬停读数、更新时间统一使用系统本地时区，并显示时区标识。涨跌配色及明暗主题遵循插件现有约定。

### R5 刷新和生命周期

进入详情时请求历史，停留期间每 30 秒自动刷新，并提供手动刷新。返回列表或关闭面板后不再发起图表请求；不要求取消已经运行的请求。图表刷新独立于普通行情刷新，不影响状态栏、列表、轮播或提醒。

### R6 反馈和失败处理

首次请求显示加载状态，失败时提供重试入口。刷新失败时保留已有曲线，标明更新失败及上次成功更新时间。无历史、无效或不足以画线的数据有明确状态。切换资产、数据源、市场或代理后，旧请求不得替换新上下文的数据。

### R7 兼容与交付

最低插件 API 从 26 提升至 29，以支持悬停读数，并同步 catalog 和文档。新增文案提供英语和简体中文翻译；保留现有设置、导入导出格式、报价和提醒行为。

## 验收标准

- [ ] AC1（R1）：点击不同资产进入相应详情；返回列表和关闭重开行为符合约定；现有标题栏功能仍可使用。
- [ ] AC2（R2、R3）：四个来源均有历史请求/解析适配；现货与合约使用正确的上游标识；图表按时间升序展示实际数据，范围及精度可见。
- [ ] AC3（R2、R4）：悬停首尾和中间位置能读取对应采样点的准确时间与价格；恒定价格、短历史和时间缺口不造成除零、伪造精度或错误时间标注。
- [ ] AC4（R4）：时间采用本地时区；明暗主题和两种涨跌颜色配置下读数、曲线、轴标注均清晰。
- [ ] AC5（R5）：进入立即请求，停留时按 30 秒周期更新；手动刷新去重；返回或关闭后无新增图表请求；既有报价与提醒周期不变。
- [ ] AC6（R6）：首载失败可重试；刷新失败保留旧曲线及成功时间；空、错误、截断、超限、异常数值响应不能替换有效历史。
- [ ] AC7（R3、R6）：快速切换、移除所选资产、变更来源/市场/代理、关闭重开及旧回调到达时，不发生资产串线或后台轮询。
- [ ] AC8（R7）：英语/简体中文、两份 README、manifest 与 catalog 一致；最低 API 为 29；相关离线测试、`noctalia plugins lint .` 和官方 validator 通过。

## 限制及待验证项

- BTC 实测 HTX/Binance 现货和合约、CoinGecko 均能取得约五分钟粒度的日内数据；不代表每个资产始终有完整 24 小时历史。
- OKX 文档支持所需参数，但当前环境返回 HTTP 403，成功访问仍需可用网络/代理环境验证。
- CoinGecko 本次匿名请求成功，但公共接口限流、权限或精度可能改变；按 R2、R6 展示实际状态。
- 研究证据与 API 能力见 `research/findings.md`。无未决产品问题；本任务仍为 planning，实施等待规划文件审核。
